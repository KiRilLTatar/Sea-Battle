# Sea Battle

Реализация игры **«Морской бой»** в виде настольного приложения на **WPF** с использованием архитектурного паттерна **MVVM (Model-View-ViewModel)**.

Проект разработан на языке **C#** и демонстрирует применение MVVM для разделения логики приложения, пользовательского интерфейса и управления состоянием игры.

## О проекте

Sea Battle — это настольное приложение, реализующее классическую игру «Морской бой».

Основной целью проекта было изучение разработки desktop-приложений на WPF и применение архитектурного паттерна **MVVM** для построения масштабируемой и поддерживаемой архитектуры приложения.

В процессе разработки была реализована игровая логика, управление игровым полем и взаимодействие пользовательского интерфейса с ViewModel.

## Стек технологий

- C#
- .NET
- WPF
- MVVM

## Реализованные элементы

- игровое поле
- размещение кораблей
- логика ходов
- обработка попаданий и промахов
- взаимодействие пользователя с игровым интерфейсом
- разделение логики приложения по паттерну MVVM

## Архитектура

Проект реализован с использованием архитектурного паттерна **MVVM (Model-View-ViewModel)**.

Основные слои приложения:

- **Model** — игровая логика и состояние игры  
- **View** — пользовательский интерфейс WPF  
- **ViewModel** — управление состоянием и взаимодействие между UI и моделью  

Такой подход позволяет разделить бизнес-логику и интерфейс, а также упростить поддержку и развитие приложения.

## Структура проекта

```text
Sea-Battle/
│
├── Models/        # игровые модели и логика игры
├── ViewModels/    # логика взаимодействия интерфейса и модели
├── Views/         # WPF интерфейс приложения
├── Commands/      # команды MVVM
└── App.xaml       # конфигурация приложения
```
